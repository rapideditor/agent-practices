
# agent-practices

A seed repository for agent scaffolding across `rapideditor` (and related) projects:
- `.github/prompts/*.prompt.md` — reusable slash commands (`/commit`, `/reflect`, `/release`, `/suggest`, `/sync`, ...)
- (optionally) `.github/instructions/*.instructions.md` — cross-project coding conventions
- (optionally) `skills/*/SKILL.md` — reusable domain knowledge blobs
